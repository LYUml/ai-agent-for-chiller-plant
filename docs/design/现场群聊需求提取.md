## 对现有 demo 的影响

1. 设备词典应覆盖 WCC1–4、CH/机号写法、CT/散热水塔、CWP、PCHWP、风机和阀。大小机、泵号、联锁和实际可控点须与现场点表核对。
2. 保留 command / strategy / query 三个入口，另将现场已执行、设备异常、控制权变化、暂停或恢复、舒适度反馈建为事件。群里的 OK、👌、谢谢可表示收到；证据不足时不能推断执行成功。
3. 优先支持查询、带原因的开机请求、多设备设定值三种回放。存储策略编号、执行者、执行模式、目标与时间、现场回复及其附件、命令回执、点位时间和逐项核实结果。
4. 历史聊天可用于语料和业务术语，当前状态查 InfluxDB，谁下发和为什么查 record。现场说法应保留来源；查询不到时标记未知。文本中没有提供可直接使用的 InfluxDB measurement、tag 或实际控制 API。
